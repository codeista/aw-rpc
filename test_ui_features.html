Test Instructions

To test Black Boat repair:

  1. Create a Black Boat at a port
  2. Create a friendly unit nearby
  3. Damage the friendly unit (have enemy attack it)
  4. Select the Black Boat
  5. Right-click on the damaged unit
  6. Look for repair context menu

To test transport loading:

  1. Create an APC at a factory
  2. Create Infantry at the same factory
  3. Move Infantry onto the APC (should auto-board)
  4. Move the APC somewhere else
  5. Right-click the APC to see blue unload positions
