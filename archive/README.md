# Archive Directory

This directory contains archived files that are no longer actively used but may be useful for reference.

## Structure

- **temp_debug/** - Temporary debug scripts and test files
  - debug_game.py - Debug script for game testing
  - diagnose_game.html - HTML diagnostic page
  - game_workaround.html - Temporary workaround page
  - json_fix.py - JSON fixing utility
  - game_data.json - Sample game data

- **old_code/** - Deprecated code and backups
  - manager_v2_backup.py - Backup of manager_v2 before recent changes

- **documentation/** - Old planning documents and notes
  - ai_planning.md - AI planning documentation
  - test_failure_summary.md - Summary of test failures during migration

## Note

These files are kept for reference but are not part of the active codebase.
They may be removed in future cleanups.
