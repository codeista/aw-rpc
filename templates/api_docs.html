AW-RPC API Documentation

Turn-based Strategy Game RPC API

POST /api/game/create
Create a new game session
Parameters:
player_name (string) - Name of the player creating the game
map_size (string) - Size of the game map (small, medium, large)
Example Request: 
{
  "player_name": "Player1",
  "map_size": "medium"
}
POST /api/unit/create
Create a new unit on the battlefield
Parameters:
unit_type (string) - Type of unit to create
x (integer) - X coordinate on the map
y (integer) - Y coordinate on the map
player_id (string) - ID of the player creating the unit
Example Request: 
{
  "unit_type": "infantry",
  "x": 5,
  "y": 3,
  "player_id": "player_123"
}
POST /api/unit/move
Move a unit to new coordinates
Parameters:
unit_id (string) - ID of the unit to move
target_x (integer) - Target X coordinate
target_y (integer) - Target Y coordinate
Example Request: 
{
  "unit_id": "unit_456",
  "target_x": 7,
  "target_y": 4
}
POST /api/unit/move2
Alternative unit movement method using unit ID
Parameters:
unit_id (string) - ID of the unit to move
direction (string) - Direction to move (north, south, east, west)
distance (integer) - Number of tiles to move
POST /api/property/capture
Capture a property on the map
Parameters:
unit_id (string) - ID of the unit capturing the property
property_id (string) - ID of the property to capture
POST /api/turn/end
End the current player's turn
Parameters:
player_id (string) - ID of the player ending their turn
game_id (string) - ID of the game session
GET /api/game/status
Get current game status and state
Parameters:
game_id (string) - ID of the game session

Response Format

All API responses follow this format:

{
  "success": true,
  "data": { ... },
  "message": "Operation completed successfully"
}

Error Format

{
  "success": false,
  "error": "Error description",
  "code": "ERROR_CODE"
}
